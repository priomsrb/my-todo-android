
This app behaves similar to Google Keep but has a few improvements:

- Unlimited nesting of TODOs
- It uses markdown as the file format
- Add TODOs using voice (including multiple items at a time)

## Installation

To generate an APK:

```shell
./gradlew :app:assembleDebug && open app/build/outputs/apk/debug/
```

Then you can transfer it to your phone to install.
